# Material Symbols

The SVG files in this directory are selected Material Symbols Rounded assets
from Google's `material-design-icons` repository:

https://github.com/google/material-design-icons

They are distributed under the Apache License 2.0:

https://www.apache.org/licenses/LICENSE-2.0

The files are unmodified except for shorter local filenames. Color and render
size are applied by the application at runtime.
